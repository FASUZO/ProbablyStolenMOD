# 存储舱标签（StorageBayLabel）使用说明

适用于《深空当铺：可能是偷的》（Probably Stolen）0.46D，版本 **1.7.1**。

本 mod 包含三部分，可分别关闭：

| 功能 | 作用 | 默认 |
|---|---|---|
| 图标标签 | 给存储舱、冰箱、酒架、储水罐、保险箱、补给箱、背包等「双击能打开窗口」的物品打自定义后缀标签，悬停与图标角标同时显示，不改物品原名，随存档保存 | 开 |
| 储水罐贴图 | 把原版单一水罐贴图换成「罐体 + 液体层」分层贴图，按容量档位显示 | 开 |
| 存储舱外观贴图 | 按原版外观变体替换存储舱贴图（三套） | 开 |

---

## 一、安装

1. 关闭游戏。
2. 把整个 `storage_bay_label` 文件夹放进：

   ```
   …\steamapps\common\Probably Stolen\Mods\
   ```

3. 启动游戏 → 主菜单 **Mods** → 勾选本 mod 激活 → **重启游戏**。

安装后文件夹应包含：

```
storage_bay_label\
├─ manifest.xml
├─ StorageBayLabel.dll
├─ README.md                 （本说明）
└─ Textures\Items\*.png      （19 张：3 张存储舱皮肤 + 16 张水罐）
```

> **为什么必须重启**：mod 清单与安全扫描结果只在启动时读取，且扫描结果按 `ModVersion` 哈希缓存。更新版本、修改清单后不重启，游戏仍在用旧结果。

## 二、给物品打标签

### 哪些物品能打标签

判定口径与游戏一致：**双击能弹出容器/机器窗口的物品**都算。包括但不限于——

| 类别 | 举例 |
|---|---|
| 存储舱 | 普通舱、大型舱、枪械舱、化学舱及其外观变体 |
| 制冷/保鲜 | 冰箱、冷冻柜、酒架 |
| 液体容器 | 储水罐、水瓶、净水容器 |
| 保险/箱柜 | 保险箱、保险箱（需开锁）、各类补给箱、战利品箱、啤酒箱 |
| 随身容器 | 背包、挎包、腰包、手提袋、存档袋 |

书籍、图纸、扫描器这类也能打开窗口的物件同样可以打标签。若只想给存储舱打，把设置里的 **「其它容器也可打标签」** 关掉即可。

### 设置

1. **右键** 目标物品。
2. 菜单底部出现 **「设置标签」**（已有标签时显示 **「编辑标签」**）。
3. 点击后弹出游戏原生的标签打印机输入框。
4. 输入文字，**回车确认**。

### 修改与清除

- 已有标签时，右键菜单会多出一个 **「清除标签」**，点它直接删除。
- 也可以在输入面板里点 **「清除」** 键，或把内容删空后回车，效果相同。
- 只关掉面板、没有确认，则不改动已有标签。

> 输入面板复用的是游戏原生的「标签打印机」（原本用来改物品自定义名称）。本 mod 接管了它的确认与清除回调，所以**用它只会改标签，不会改动物品原名**。

### 长度

默认最多 **12 个字**，可在设置里调整到 4–16 字。超出部分自动截断（不会报错）。

### 显示位置

| 位置 | 效果 |
|---|---|
| 悬停介绍 | 名称行末尾追加 ` · 标签`，例如 `储物舱 · 食物` |
| 图标角标 | 图标角上的小底板 + 文字，默认左下角 |

标签**不修改物品原名**：交易、日志、负重大小提示等文本仍是原版名称；标签作为物品的一个自定义标记随物品写进存档，移动、装箱、退出重进都不会丢。

## 三、设置项

入口：主菜单 **Mods** → 存储舱标签 → **设置**。

| 分组 | 设置项 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 角标 | 在图标上显示标签 | 开 | — | 关闭后标签仍保存在存档里，只是不再画在图标上 |
| 角标 | 角标位置 | 左下 | 左下 / 左上 / 右下 / 右上 | 四角可选 |
| 角标 | 字号缩放 (%) | 100 | 60–160 | 100 = 按图标尺寸自动计算 |
| 角标 | 底板不透明度 (%) | 55 | 0–100 | 0 = 完全透明，只留文字与阴影 |
| 角标 | 文字阴影 | 开 | — | 柔和黑边，浅色贴图上小字更清楚；关闭后改用细描边 |
| 常规 | 悬停介绍显示名称后缀 | 开 | — | 关闭后只在图标上显示角标 |
| 常规 | 其它容器也可打标签 | 开 | — | 关闭后只有存储舱能打标签，冰箱/酒架/水罐等不再出现菜单项 |
| 常规 | 标签最大字数 | 12 | 4–16 | 超出自动截断 |
| 常规 | 储水罐水位贴图 | 开 | — | 关闭则回到原版水罐贴图 |
| 常规 | 存储舱外观贴图 | 开 | — | 关闭则回到原版存储舱贴图 |

所有设置**即时生效**，不需要重启，也不需要重新读档。

配置文件位置（手动改也行，改动后重启游戏）：

```
%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\ModConfigs\storage_bay_label.json
```

## 四、自定义贴图

把 PNG 放进 `storage_bay_label\Textures\Items\`，**文件名即资源键**，重启游戏后生效。请保持与原版相同的像素尺寸，否则显示大小会不对。

### 存储舱皮肤（48×48）

| 文件名 | 替换的原版外观 |
|---|---|
| `bay_skin.png` | `storage_bay`（外观变体 1） |
| `bay_skin_2.png` | `storage_bay1`（外观变体 2） |
| `bay_skin_3.png` | `storage_bay2`（外观变体 3） |

变体 2/3 缺文件时会共用 `bay_skin.png`。只替换渲染贴图，物品占格、网格对齐与存档均不受影响。

### 储水罐（64×64）

| 文件名 | 作用 |
|---|---|
| `tank_body.png` | 罐体（空罐状态的基础层） |
| `tank_<基色>_<档位>.png` | 液体层，档位为 `10 / 25 / 50 / 75 / 100` |

内置三套基色：`blue`、`dark`、`red`，例如 `tank_blue_50.png`。液体层会按容器内液体的实际颜色着色，因此贴图本身不必上色。

> 若容器液体的基色名不在这三套之内，就找不到对应的液体层贴图，此时只会显示罐体外观（**容量数值与所有机制不受影响**）。想覆盖更多颜色，按 `tank_<基色>_<档位>.png` 的命名补图即可。

## 五、日志与排查

日志文件：

```
%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\Player.log
```

> 游戏内 **F8** 控制台不镜像 `Debug.Log`，F8 里看不到本 mod 的输出是正常现象，排查一律以 `Player.log` 为准。

启动后日志里正常会有这几行（前缀 `StorageBayLabel`）：

```
init v1.7.1
enabled; waterTank=ok baySkin=ok
```

| 现象 | 排查方向 |
|---|---|
| **所有功能同时失效**（悬停后缀、角标、右键菜单全部没有） | 九成是 `manifest.xml` 格式错误，游戏直接跳过整个 mod。日志开头会有 `[ModLoader] Failed to parse manifest.xml in …\storage_bay_label: … skipping`，且 mod 不在随后的 `audit:` 列表里。用记事本打开确认每个标签都成对闭合（`<Description>…</Description>`），或直接在 mod 目录跑一次 `build.bat`，它会先做 XML 校验 |
| mod 未出现在 Mods 列表 | `manifest.xml` 与 `StorageBayLabel.dll` 是否都在 `Mods\storage_bay_label\` 下；确认没放成两层同名文件夹 |
| 激活被拒，提示 `Undeclared capabilities: reflection-external` | 用最新 `manifest.xml` 覆盖；本 mod 需要该权限（读取运行时合成的游戏类型），之后必须重启游戏 |
| 右键没有「设置标签」 | 该物品双击打不开容器窗口（如材料、成品、存储舱扩容套件）；或设置里关了「其它容器也可打标签」而它又不是存储舱；或菜单已满、无空余隐藏按钮，日志会有 `no hidden context button` |
| 角标不显示 | 先看设置里「在图标上显示标签」是否为开；再看是否打开了设置面板或其他弹窗（会被刻意隐藏）；最后确认存储舱确实有标签 |
| 悬停有后缀但图标上没有角标 | 只可能出在角标开关或弹窗遮挡；若设置都是开的且无弹窗，把 `Player.log` 里以 `StorageBayLabel` 开头的行发回来 |
| 悬停没有后缀 | 检查「悬停介绍显示名称后缀」；只有物品悬停介绍会追加，事件日志与交易文本不会 |
| 更新版本后行为没变 | 没重启。清单与扫描结果只在启动时读取 |
| 标签"丢失" | 标签挂在物品上，不是挂在格子或存储舱位置上。若换了一个同型号存储舱，原标签不会跟过来 |
